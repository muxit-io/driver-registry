Changelog

## 0.3.1 - First version in the Muxit driver repo, with a `template.js` connector (`dali`) that the bundled "DALI status" dashboard and `dali-monitor` script bind to. - The serial port is no longer opened with an empty line delimiter, and `release` leaves raw mode only after closing the port. Muxit's line splitter loops forever on an empty delimiter, so data arriving outside raw mode could hang the serial receive thread. - When the interface does not answer the LUBA settings command at `open`, the port is closed again instead of staying open with `connected: true`.

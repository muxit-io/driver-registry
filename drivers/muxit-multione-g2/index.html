Changelog

## 0.1.4 - **`online` now updates by itself.** A heartbeat checks `GET /server/v1/status` every `heartbeatMs` (default 5000, 0 = off), skipped while another call runs, so a dashboard shows when Workflow G2 is stopped or started without any button press. New property `serviceMessage` says it in words. Heartbeat calls don't touch `lastResponse` or `lastError`. - The `multione` template hands the port over with the `dali` connector's `usbRelease` / `usbOpen` (LunatoneLuba 0.4.0 renamed `release` / `open`). **If you use the `multione` connector, update the LunatoneLuba driver to 0.4.0 too.** The "MultiOne G2" dashboard binds `dali.usbConnected`.

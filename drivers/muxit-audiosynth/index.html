AudioSynth

v1.5.0 DLL utilities by muxit

Software audio synthesizer. Plays tones, musical notes, and short melodies — useful for lab-side audible notifications, robot/CNC feedback tones, and experiment-complete bell sounds. Polyphonic via overlap: true so notes can ring into each other; long-tail presets (bell, marimba) decay naturally past the gate-on duration. Streams Opus-encoded audio to every connected dashboard by default; can also (or instead) play locally via NAudio on Windows hosts. Four waveforms, ADSR envelopes, additive harmonics, and presets (beep / bell / pluck / pad / marimba).

Changelog

## 1.5.0 ### Features - **Polyphony.** `playTone`, `playNote`, `playMelody`, and `beep` now accept `overlap: true`. The note is mixed on top of whatever voices are already ringing and the action returns at the gate-off so the next call can start before the tail finishes. The previous replace-not-queue behaviour is the default (`overlap: false`) — existing scripts and connectors continue to work unchanged. - **Release tails ring out past gate-off.** Long-decay presets like `bell` and `marimba` are no longer compressed into the requested duration — a 200 ms bell now decays for its full ~1.5 s natural tail instead of being suddenly cut off. The action call still blocks until the tail finishes when `overlap` is `false`; `playing` reflects the full tail-out window. - **Polyphonic NAudio output** runs through a single persistent `WaveOutEvent` driven by a sample-mixer, so overlapping voices on Windows host playback don't spawn an output device per note. - **Polyphonic streaming output** uses the host's new live encoder session — one long-lived Opus encoder spans every overlapping voice and a 1 s post-silence linger window, so back-to-back overlap calls don't restart the encoder and glitch the browser-side decoder. ### Notes - Requires the matching MuxitServer host change (adds `AudioStreamReaderEmitter` on `IConnectorDriver`). Older hosts will fall back to monophonic streaming when `overlap: true` is requested in browser mode — NAudio polyphony still works.

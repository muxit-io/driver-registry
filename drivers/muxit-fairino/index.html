Fairino

v1.2.0 DLL motion by muxit

Fairino collaborative robot driver (FR3/FR5/FR10/FR20 and similar) — communicates via the controller's native XML-RPC protocol on port 20003, with real-time state over CNDE (port 20005, firmware 4.x) or the legacy stream on port 20004. Background state monitor caches joints, TCP pose, motion status and safety alarms so property reads return instantly. Joint (MoveJ), straight-line (MoveL) and Cartesian point-to-point (MoveCart) motion that always runs with the robot's active tool and workpiece frame, waits or queues on request, plus forward/inverse kinematics, digital/analog I/O (read and write), force sensing, and the controller's fault codes translated to text. Streams JSON state snapshots at the configured poll rate.

Changelog

## 1.2.0 - **Real-time state over CNDE (port 20005).** Firmware 4.x — and the official SDK since C#SDK-V1.3.2 — use CNDE: the driver subscribes to the fields it needs at `statePeriodMs` (default 8 ms). New `config.stateStream`: `auto` (default) tries CNDE first and falls back to the legacy 20004 packet, so 3.x controllers keep working without changes; `cnde` / `legacy` force one. `stateProtocol` reports which transport is in use. - **New CNDE-only properties** (null on the legacy stream): `speedScaleAuto`, `speedScaleManual`, `collisionLevel`, `safetyDoorAlarm`, `safetyPlaneAlarm`, `motionAlarm`, `interfereAlarm`, `singularPose`, `softLimitExceeded`, `abnormalStop`, `programRunState`, `luaFileName`, `luaLineNumber`. Firmware that doesn't know them gets the core field set only. - New config: `cndePort` (20005), `statePeriodMs`. `pollIntervalMs` was never used and is dropped from the template.
